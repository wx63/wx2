# 系统状态盘点 - 2026-08-13

## 当前状态

- 前端/后端服务运行在 http://localhost:3001/
- 飞书长连接已启动，消息进入 `executeAgentCommand` 的 Agent 编排链路
- Agent 模式默认 `agentic`，模型可调用平台内部工具后汇总回复

## 本次新增：飞书实时查价

- 新增 `server/price-lookup.js`：
  - 数据源：慢慢买公开折扣搜索、苹果中国官网
- 支持任意商品关键词：手机、数码、家电、日用等均可查询
- 车型查询接入汽车之家指导价，支持日产 N7、雅阁、凯美瑞、Model Y 等常见品牌车型
- 普通商品接入慢慢买全商品报价源（c=price），折扣库没收录时继续查全量商品库
- 最后一级兜底为公开搜索页；即使电商库和车型库都没有，也会返回可核验的实时搜索入口，不再硬性“查不到”
- 对 iPhone 17 / 华为 Mate70 等系列做型号识别，并过滤配件、仿冒品和国际版（用户明确要求国行时）
  - 返回当前可见最低价、渠道、时间、官方参考价和下单提示
- 新增 `price_lookup` Agent 工具：
  - 飞书 Agent 在收到“价格 / 最低价 / 多少钱 / 报价 / 售价”类指令时调用
  - 如果模型没有主动调用，系统会在 agentic 链路中强制执行一次查价
- 调整 `server/bridge.js` 系统提示：
  - 不再禁止所有实时信息查询，而是明确实时价格使用 `price_lookup`

## 验证

- `node --check` 通过
- 直接调用 `lookupPrice()` 成功返回实时价格
- Agent 工具调用测试成功：模型自动调用 `price_lookup` 并返回结构化价格报告
- 通用商品实测：戴森吹风机、戴森 HD15、华为 Mate70、SONY WH-1000XM5 均可返回价格
- 车型实测：日产 N7、本田雅阁、丰田凯美瑞、特斯拉 Model Y 均返回汽车之家指导价
- 罕见商品实测：老铺黄金手镯可查到具体金饰报价；无收录商品会返回实时搜索页

## 注意

- 价格数据来自公开折扣页，下单前仍需确认国行/联保/国补资格和实际到手价
- 京东、拼多多等平台页面有登录/风控，当前主要使用慢慢买聚合结果，后续可继续接入官方 API
