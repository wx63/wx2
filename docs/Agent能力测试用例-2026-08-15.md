# Agent 能力测试用例 — 2026-08-15

> 用途:对系统 Agent 编排能力做一轮完整验收。
> 覆盖:路由 → 任务拆解 → 工具调用 → 审批闸门 → 飞书端到端 → 边界容错 → 性能基线。
> 每条用例含:目的 / 步骤 / 预期 / 判定。可用 **浏览器前端** 或 **curl** 任一方式执行(推荐 curl 可重复跑)。

## 〇、测试准备

### 0.1 前置条件

- 后端 :3001 运行中,Gateway :18789 运行中(检测确认过)。
- `.env` 中 `ADMIN_EMAIL` / `ADMIN_PASSWORD` 可用;`OPENCLAW_DIRECT_MODEL` = `deepseek/deepseek-chat`。
- 数据库可查(验证落库):`data/app.db`。

### 0.2 curl 登录辅助(每次会话开头跑一次)

```bash
cd "E:\基于OpenClaw构建跨境电商智能体\基于OpenClaw构建跨境电商智能体"
source <(grep -E "^(ADMIN_EMAIL|ADMIN_PASSWORD)=" .env | sed 's/^/export /')
curl -s -c /tmp/oc.jar -X POST http://localhost:3001/api/auth/login \
  -H "Content-Type: application/json" \
  -d "{\"email\":\"$ADMIN_EMAIL\",\"password\":\"$ADMIN_PASSWORD\"}" | head -c 200
# 预期: {"ok":true,"user":{...}} → cookie 已写入 /tmp/oc.jar
```

### 0.3 指令执行 + 查结果(通用模板)

```bash
# 1) 提交指令(异步)
RESP=$(curl -s -b /tmp/oc.jar -X POST http://localhost:3001/api/command \
  -H "Content-Type: application/json" -d '{"command":"你的指令文本"}')
echo "$RESP"   # 预期返回 ok:true + commandId
ID=$(echo "$RESP" | node -e "let s='';process.stdin.on('data',d=>s+=d).on('end',()=>console.log(JSON.parse(s).commandId||JSON.parse(s).id||''))")
# 2) 轮询执行结果(注意:status 在 data 嵌套里)
for i in $(seq 1 30); do
  R=$(curl -s -b /tmp/oc.jar http://localhost:3001/api/commands/$ID)
  echo "[$i] $R" | head -c 400; echo
  echo "$R" | grep -qE '"(done|success|ok|failed|error)"' && break
  sleep 3
done
# 3) 查 agent 编排轨迹(落库)
curl -s -b /tmp/oc.jar http://localhost:3001/api/commands/$ID/run
```

## A. 路由测试(验证"运营总监"按关键词分派正确数字员工)

| # | 用例 | 指令 | 预期 |
|---|---|---|---|
| A1 | 路由→市场调研 Agent | `做一份宠物用品美国站竞品周报,重点看价格与差评关键词` | routeAgent = 市场调研 Agent;回复含竞品/价格分析 |
| A2 | 路由→内容与视觉 Agent | `为便携折叠宠物水壶生成英语西语日语三语 Listing 五点描述 + SEO 标题` | routeAgent = 内容与视觉 Agent;回复含 listing 草稿 |
| A3 | 路由→获客与社媒 Agent | `为 3 个 X 账号排期今日 9 条内容,间隔 6-18 分钟` | routeAgent = 获客与社媒 Agent;含排期方案 |
| A4 | 路由→客服(默认兜底) | `客户说尺码表里 XL 对应胸围多少?` | routeAgent = 客服与订单 Agent |
| A5 | 问候语走本地快路径 | `你好` / `早上好` / `thanks` | 本地 orchestrator 快速回复(Greeting 步骤),**不调 LLM、不触发工具**,耗时 <3s |

**判定标准**:A1-A4 的 `/api/commands/:id/run` 返回的 routeAgent 与 ROUTE_RULES 关键词映射一致;A5 的 plan 含 Greeting 步骤、model=`orchestrator`、duration <3s。

> ⚠️ **双执行路径(2026-08-15 冒烟实测确认)**:系统有两条编排路径——
> 1. **agentic(LLM)**:非问候语 + AGENT_MODE 命中 agentic → `runAgenticCommand` 直连 deepseek(21-27s,带工具调用);
> 2. **orchestrator(本地)**:问候语或 agentic 失败回退 → 本地 plan(route/greeting/kb/…),无 LLM、毫秒级。
> 测试时注意区分:指令没走 LLM ≠ 系统故障,可能命中了本地快路径。

## B. 工具调用测试(验证 Agent 能自主调工具)

| # | 用例 | 指令 | 预期 |
|---|---|---|---|
| B1 | price_lookup 实时查价 | `iPhone 16 现在多少钱,全网最低价是多少` | 触发 price_lookup;回复含实时价格/折扣,agent_steps 里 tools 出现 price_lookup |
| B2 | kb_query 知识库检索 | `退换货政策是什么?支持几天内无理由退?` | 触发知识库检索;回复**带来源引用**(文件名/章节) |
| B3 | listing 工具 | `生成一个宠物自动喂食器的 listing` | 触发 listing 工具;输出 SEO 标题 + 五点描述草稿 |
| B4 | localize 本地化 | `把"防水防滑,适合户外"本地化为越南语,注意货币表述` | 触发 localize;输出越南语 + 本地化说明 |
| B5 | compliance 合规审查 | `审查这段文案是否有敏感词或 FDA 禁用表述:clinically proven to cure` | 触发 compliance;输出违规点清单,命中"clinically proven" |
| B6 | 多工具链(查价+打标) | `查一下这款狗窝的最低价,并把这个线索标记为高意向` | 依次/并行触发 price_lookup + 打标;两步都落 agent_steps |

**判定标准**:`agent_steps` 表中 steps.tool 与预期工具一致;回复内容由工具结果加工,而非纯 LLM 编造。

## C. 任务拆解与编排(验证真实落库与轨迹展示)

| # | 用例 | 指令 | 预期 |
|---|---|---|---|
| C1 | 多步任务拆解 | `做一份东南亚市场趋势预测,并生成 3 条 TikTok 爆款脚本` | agent_runs 落库;agent_steps ≥ 2 步(调研→内容);前端轨迹面板展示每步 |

**判定标准**:C1 的 agent_runs.agent_run_id + agent_steps.step_order 完整;C2 前端能看到真实执行轨迹(非假数据)。

## F. 边界与容错

| # | 用例 | 输入 | 预期 |
|---|---|---|---|
| F1 | 空指令 | `""` / 纯空格 | 400 + 中文提示,不调模型不落库 |
| F2 | 超长指令 | 5000 字 | 400(长度限制)或正常执行但不崩溃 |
| F3 | 无关键词混杂指令 | `今天天气怎么样顺便看看选品` | 路由命中其中一个 agent,正常返回 |
| F4 | 纯英文 | `write a listing for a foldable dog bowl` | 正常路由到内容 Agent,英文回复 |
| F5 | 工具全挂回退 | 断网后发查价指令 | 不 5xx;回退到 Gateway 或返回可读错误(agentic_fallback) |
| F6 | 并发提交 | 1 秒内连发 3 条不同指令 | 3 条都异步排队;各自落库;互不覆盖 |

**判定标准**:F1/F2 明确报错不崩;F5 无裸异常,路径标记 fallback;F6 三条 agent_runs 均存在且 id 不同。
