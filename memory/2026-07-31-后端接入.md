## ⚠️ 重大踩坑：PowerShell 编码损坏（血的教训）

**事故**：用 `Set-Content -Encoding UTF8` 写 app.js 导致全文件中文字符损坏（211 行乱码）
**原因**：Windows PowerShell 5 的 `Get-Content` 默认按 GBK 读取 UTF-8 文件，读写编码不一致
**恢复**：从 Claude Code 会话日志（`~/.claude/projects/.../a3322ce5...jsonl`）提取了 app.js 完整 Write 记录，还原成功
**规则**：
1. **永远用 Python 或 write 工具改文件，不用 PowerShell 的 Get/Set-Content 处理 UTF-8 中文文件**
2. 改文件前先备份（`Copy-Item xxx xxx.bak`）
3. 大型 JS/HTML 文件修改用 `edit` 工具，不要整文件重写
4. 项目文件建议尽早 git init，避免依赖会话日志恢复
