## 生产部署修复：HTTP 会话 Cookie

- 远程 `http://106.55.18.244:3001` 登录返回 200，但响应没有 `Set-Cookie`，后续请求全部 401。
- 根因：生产模式原先固定 `cookie.secure: true`，express-session 在非 HTTPS 请求下不会下发 Secure Cookie。
- 修复：`SESSION_COOKIE_SECURE=auto` 默认按请求是否 HTTPS 自动决定；HTTP 直连可登录，HTTPS 反代仍会使用 Secure Cookie，也可显式设 `true` / `false`。
- 验证：本地 `NODE_ENV=production` + HTTP 下登录返回 `oc.sid`，`/api/auth/me` 200；`npm test` 与前端测试全绿。

## 远程页面问题修复：未登录根路径应跳转登录页

- 现象：`http://106.55.18.244:3001/` 未登录时显示空控制台壳，而不是登录页，看起来像页面没做好。
- 根因：`apiJson("/api/auth/me")` 对 `/api/auth/` 路径不主动跳转，`loadUser()` 只处理抛错，没有识别 `{ok:false}`，于是未登录时留在控制台空壳。
- 修复：`loadUser()` 在 `!data.ok || !data.user` 时调用 `redirectToLogin()`；前端冒烟新增“未登录根路径跳转登录页”回归测试。
- 验证：`npm run test:frontend` 5/5；`npm test` 44/44；更新包 `deploy/ecommerce-agent-update-20260816-1349.zip` 不含 data。
