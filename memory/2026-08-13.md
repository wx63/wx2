## 飞书实时查价

- 飞书消息此前不能实时查价，因为 Agent 工具注册表只有本地业务工具，且 bridge 系统提示禁止联网。
- 本次新增 `server/price-lookup.js` 和 `price_lookup` 工具。
- 飞书收到“价格/最低价/多少钱/报价/售价”类指令时会调用 `price_lookup`，模型未调用时也会强制补一次查价。
- 当前价格源为慢慢买公开折扣页 + 苹果中国官网；京东/拼多多直连仍受登录和风控限制。
- 验证：Agent 工具调用测试成功，模型自动调用工具并返回实时价格。
- 已扩展为通用商品查价，不再局限于 iPhone：支持任意商品关键词，并过滤配件、仿冒品、非目标型号。
- 车型价格接入汽车之家指导价；日产 N7 等车型不再返回“适配 N7”的周边配件。
- 通用价格链路：慢慢买折扣库 → 慢慢买全商品库 → 公开搜索页兜底；不出现硬性“查不到”。
