# 2026-08-03 · 知识库页接通真实后端（上传/删除/RAG）

## 背景
AGENTS.md 尾巴项「前端知识库页接后端真实文件列表」。前端知识库页原本是 5 条 mock 数据，上传/向量化/删除全是前端假动作。

## 改动

### 后端
- `server/kb.js`：`loadKnowledgeBase()` 索引范围从 `.md` 扩到 `.md + .txt`；新增 `fileStats()` 按文件聚合 `{chunks, chars}` 并导出。
- `server/index.js`：引入 multer 2.2.0。
  - `POST /api/kb/upload`：multipart 落盘进 `知识库/`，文件名 `时间戳-原名`（防重名），`.md/.txt` 上传后立即调 `loadKnowledgeBase()` 重载索引。
  - `DELETE /api/kb/files/:name`：`decodeURIComponent` + `path.basename` 安全校验（拒目录穿越），删盘 + 重载索引。
  - `GET /api/kb/files` 增强：返回 `{name, size, mtime, indexed, chunks}` + `totalChunks`，按 mtime 倒序。
  - **multer 中文文件名坑**：multer 2.x 的 `file.originalname` 是 latin1 编码，中文文件名直接用会落盘成乱码。filename 回调里需 `Buffer.from(orig, 'latin1').toString('utf8')` 转回 UTF-8。

### 前端（app.js）
- `KB_DOCS` 初始改空数组，启动由 `loadKBFilesFromServer()` 从后端拉真实文件覆盖。
- 新增 `loadKBFilesFromServer()`（仿 `loadApprovalsFromServer` 范式），`switchView` 切到 knowledge tab 时也刷新。
- `addKBFiles()` 改真实上传：FormData + `POST /api/kb/upload`，成功后用后端真相覆盖列表。
- 删除按钮改真实：`DELETE /api/kb/files/:name`，乐观删除 + 失败恢复。
- `KB_STATUS` 加 `not_indexed`/`uploading`；`renderKBList` 加对应分支；stats 的「处理中」改为统计 uploading 状态。
