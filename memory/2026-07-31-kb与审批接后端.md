### 2. kb-query 技能落地（server/kb.js）
- **分块**：按二级标题 `##` 切，每块带 file + heading + content
- **检索**：关键词分词（英文/数字拆子串 + 中文 2-3 gram + 单字 + 同义词扩展如「衣服→女装/男装」），标题命中权重 ×3，正文 ×1，取 Top-3
- **生成**：把检索块作 context 注入，调 OpenClaw 生成**带来源引用**的答复草稿
- API：`POST /api/kb-query` + `GET /api/kb/retrieve`（调试）+ `GET /api/kb/files`

**踩坑**：
- 「这件衣服有 XL 吗 165cm 55kg」一开始检索不到女装块——因为 tokenize 把 `165cm` 当整体 token，但表里是分散的 `165`。**解法**：对每个字母数字段再拆出纯数字子串（`165cm`→`165cm`+`165`+`cm`）。
- 「衣服」匹配不到「女装尺码表」标题。**解法**：加同义词表 SYNONYMS，2-gram 命中「衣服」时自动扩展出「女装/男装/服装/上衣」token。
